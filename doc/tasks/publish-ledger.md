# 模块任务: 发布素材与台账模块

模块目标：汇总审核通过任务的发布素材包，并记录人工或半自动发布后的平台台账。

## Checklist

- [ ] 定义 `POST /api/jobs/export-publish-package` 请求结构，包含 `taskId` 和 `platforms`。
- [ ] 定义素材包响应结构，包含 `packageUrl` 和 `items`。
- [ ] 定义 `items` 字段，覆盖视频、封面、标题、简介、标签、GitHub 链接、推荐发布时间和平台备注。
- [ ] 校验任务状态必须为 `approved` 才能导出发布素材包。
- [ ] 从存储层读取视频产物。
- [ ] 从存储层读取封面产物。
- [ ] 从存储层读取脚本文案。
- [ ] 从候选项目读取 GitHub 项目链接。
- [ ] 生成平台通用素材清单。
- [ ] 为抖音生成平台备注占位。
- [ ] 为视频号生成平台备注占位。
- [ ] 为 B 站生成平台备注占位。
- [ ] 为小红书生成平台备注占位。
- [ ] 打包 MP4、封面、标题、简介、标签和链接说明。
- [ ] 将素材包保存到对象存储。
- [ ] 写入素材包产物元数据。
- [ ] 定义 `POST /api/publish-records` 请求结构。
- [ ] 校验发布记录必须包含 `taskId`、`platform`、`publishedAt`、`operator`。
- [ ] 支持人工发布后补充 `publishUrl`。
- [ ] 写入 `PublishRecord`。
- [ ] 发布记录写入成功后通知控制面更新为 `published_manual`。
- [ ] 禁止未审核通过任务写入发布完成状态。
- [ ] 禁止保存明文平台账号密码字段。
- [ ] 禁止实现绕过登录、验证码、审核或风控的自动化逻辑。
- [ ] 写入发布模块运行日志。
- [ ] 编写审核通过任务素材包导出测试。
- [ ] 编写素材包字段完整性测试。
- [ ] 编写发布记录补充平台链接测试。
- [ ] 编写未审核通过任务禁止发布测试。
- [ ] 编写账号密码字段拒绝测试。

## 完成定义

- [ ] 审核通过任务可导出完整发布素材包。
- [ ] 人工发布结果可记录到台账。
- [ ] 模块不保存平台账号密码，不绕过平台风控。
