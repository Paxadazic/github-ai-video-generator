# 模块任务: 自动质量检查模块

模块目标：在人工审核前检查产物完整性和基础质量，避免明显失败产物进入审核。

## Checklist

- [ ] 定义 `POST /api/jobs/quality-check` 请求结构，包含 `taskId`、`scriptUrl`、`audioUrl`、`subtitleUrl`、`videoUrl`、`coverUrl`。
- [ ] 定义质检响应结构，包含 `taskId`、`passed`、`checks`。
- [ ] 定义单项检查结果结构，包含 `name`、`passed`、`message`。
- [ ] 实现视频文件存在检查。
- [ ] 实现视频文件可播放检查。
- [ ] 实现音频文件存在检查。
- [ ] 实现音频时长读取。
- [ ] 实现视频时长读取。
- [ ] 实现音频时长与视频时长差异不超过 1 秒检查。
- [ ] 实现字幕文件存在检查。
- [ ] 实现字幕 JSON 可解析检查。
- [ ] 实现字幕时间戳递增检查。
- [ ] 实现脚本 JSON 可解析检查。
- [ ] 实现标题不为空检查。
- [ ] 实现简介不为空检查。
- [ ] 实现 GitHub 链接有效性检查。
- [ ] 实现脚本占位符残留检查。
- [ ] 实现 JSON 解析失败残留文本检查。
- [ ] 实现明显虚构事实关键词检查，覆盖性能指标、融资信息、官方背书等高风险类别。
- [ ] 实现封面文件存在检查。
- [ ] 实现每个检查项独立返回结果。
- [ ] 实现任一关键检查失败时 `passed: false`。
- [ ] 实现质检失败错误写入任务 `lastError`。
- [ ] 实现质检通过后通知控制面可进入 `review_pending`。
- [ ] 写入质量检查模块运行日志。
- [ ] 编写可播放视频通过测试。
- [ ] 编写损坏视频失败测试。
- [ ] 编写音视频时长差异失败测试。
- [ ] 编写乱序字幕失败测试。
- [ ] 编写空标题或空简介失败测试。
- [ ] 编写占位符残留失败测试。
- [ ] 编写质检响应契约测试。

## 完成定义

- [ ] 质量检查能明确指出失败项。
- [ ] 失败产物不会进入人工审核。
- [ ] 通过产物满足 PRD 的基础验收约束。
